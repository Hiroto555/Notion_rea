## 実装順序

1. 通常のテストコマンドとPlaywright設定にGUIの明示実行ガードを設ける。
2. 通常ページの反復複製で並び順が衝突する問題と、複製タイトルの長さ制限を修正する。
3. 添付ファイル・完全バックアップの書き込み順序を改善し、障害注入で検証する。
4. 壊れたページの原本を保全しながら、正常ページの読み込み・検索を継続できるようにする。階層情報を証明できない操作は停止する。
5. 同期の設計・独立モジュールを作る。既存の保存receipt、未保存入力、端末識別、復元と整合するまでは実アプリに接続しない。
6. 見た目や実画面での操作確認をまとめて後続のGUI試験へ送る。
