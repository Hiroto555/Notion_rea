# Folio W3 開発版：Callout・簡易表

W2完成版 `925960f8aeeb9b6e2d0b33b4135f7cf2e221d42a` を基点にした、macOSローカル用の開発版です。Listビュー・Status・クラウド・外部公開は今回の範囲に含みません。

## 起動

Finderで `scripts/launch-r9.command` を開くか、このworktreeで次を実行します。

```sh
node scripts/r9-demo.mjs
```

専用データは `output/r9-demo/data`。通常利用のworkspaceやW1/W2のデータを選ばず、初回だけ合成サンプルを作ります。二回目以降は編集したサンプルをそのまま開きます。認識できないディレクトリ、シンボリックリンクによるデータ差替えは拒否します。

ビルドを作り直す場合は `npm run build`。一般の `npm start` はデータディレクトリを明示しないため、検収には上の専用ランチャーを使ってください。

## 試す操作

1. 最初に開く「W3｜考えを伝えるページ」で、色付きのCallout内にカーソルを置く。「メモ」「ヒント」「注意」を切り替え、本文を編集する。
2. 「コールアウトを解除」で通常のブロックに戻す。Undoで元に戻り、本文やブロックIDが保持されることを確認する。
3. 表のセルをクリックし、行・列の追加と削除、「見出し行」を試す。Tab/Shift+Tabでセル移動、最後のセルのTabで行追加、Command+Enterで表の外へ移動できる。
4. 空の段落で `/` を入力し、「コールアウト」または「簡易表」を選ぶ。`/callout`、`/table` でも絞り込める。
5. 保存済み表示を待って別ページへ移動し、戻る。Markdownを書き出して別ページとして取り込む。再起動後も内容を確認する。
6. 狭いウィンドウで列を増やす。横長の表は表の内側だけでスクロールする。

## 対応範囲

- Calloutはメモ・ヒント・注意の3種類。内部に既存ブロックを保持でき、解除で子ブロックを取り出せます。
- 簡易表は最大100行・20列。セル内は段落、改行、文字装飾、リンクに対応します。セル結合、入れ子の表、セル内の画像やリストは対象外です。
- 最後の行または列の削除は表全体の削除になります。Undoで戻せます。
- 対応しないHTML表は、整形して内容を落とす前にエラーで拒否します。表の中へ表全体を貼り付ける操作も拒否します。
- Markdownでは新しいブロックを読みやすいHTMLとして書き出します。Folioでの往復を検証しています。一般のMarkdownアプリによる同じ表示は保証していません。

## 保存と互換性

新ブロックを含む本文だけ `doc.schemaVersion = 2` になります。ページ、SQLite、バックアップの既存形式は変更していません。通常の本文はバージョン1を維持します。

プロセス内で最初に新ブロックを保存する前に、検証済みの `before-rich-blocks` 全体バックアップを作成します。失敗した場合はDBへの変更を止め、未保存の入力と復旧用draftを保持します。保存結果が不明な操作を無条件に再送することはありません。

ブロックID、同一ページの一回限りのcut移動、コピーの新ID、Undo、履歴、クラッシュ復旧、portable recovery、全体バックアップを通じて新ブロックを扱います。

W2の実ビルドで、新しい本文を読み取り専用にし、原本を変更しないことを専用コピー上で確認しています。旧版へ戻す場合も新版の実データを直接開かず、バックアップを新しいworkspaceへ復元して使ってください。

## 検証の再実行

```sh
npm run build
npm test -- --maxWorkers=4 --testTimeout=15000
npx playwright test
node scripts/r9-screenshots.mjs output/r9-visual-new
node scripts/r9-compatibility.mjs ../Folio-r8-integration output/r9-compatibility-new
```

画面・互換性スクリプトは新しい出力先を指定します。既存の出力先は上書きしません。大容量の復旧境界テストには15秒の試験上限を指定します。これは製品のタイムアウト変更ではありません。

物理キーボードによる日本語IMEの実変換、実利用データ、停電・ディスク障害、署名付き配布、他OSは未確認です。自動試験のcompositionイベントと実IME操作を区別しています。
