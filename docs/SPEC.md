# Folio仕様 0.1

## 目的と根拠

ユーザー要求のページ階層・ブロック編集・ローカル保存を実装する。REAのNotionディレクトリ観察と公開ヘルプのブラウザー観察を証拠として残す。内部モデル・非公開IPCの仕様はUNKNOWNであり、Folioの設計は独立したもの。現行のNotionライセンスと深い抽出の許諾が確定していないため、ASARの抽出、デコンパイル、ログインや認証情報の調査を実施していない。

## 操作と不変条件

- 左にページツリー、中央に編集領域、右に任意表示の情報・アウトライン・バックリンク。右ペインはユーザー要求に基づくFolioの設計で、Notionに常設の3カラムがあると主張しない。
- ページIDはUUID。親子関係はparentId。兄弟順序はposition。自身・子孫への移動を拒否する。移動はトランザクションで行う。
- ページ複製は子孫も複製し、新IDを割り当てる。本文中のリンク先は元のページIDを維持する。
- 削除はゴミ箱への論理削除。子孫も対象。以前から削除済みの別ページを誤復元しない。削除済み親から子だけ復元する場合は最上位に戻す。
- 編集は即時描画し、IPC保存を直列化。revisionによって古い書き込みを拒否。失敗時はエラー表示し、自動で成功扱いにしない。
- 本文形式はProseMirror JSON。HTMLを真の保存形式としない。最大リクエスト32MB、本文ノード10万・深度100まで。
- 文字列検索はタイトル・本文・データベース行と値を対象。日本語の部分一致を優先した全走査であり、FTSランキングや形態素解析ではない。
- Undo/Redoは開いている本文エディタの操作履歴。ページ移動・タイトル・データベース・アプリ再起動をまたぐ汎用Undoではない。
- 変更履歴は本文保存前のスナップショットを最大100件保持。タイトル単独やDBプロパティの履歴は対象外。

## ブロック

段落、H1–H3、箇条書き、番号リスト、チェックリスト、トグル、引用、コード、区切り線、画像。太字・斜体・取り消し線・下線・インラインコード・リンク。ネイティブHTML/テキストのコピー＆ペーストをProseMirrorで解析する。

スラッシュメニューは段落先頭の `/` から開始。検索、上下キー、Enter、Escapeを実装。ブロックハンドルはトップレベル単位。Shiftクリックによる複数選択、上下移動、ドラッグ、複製、削除を提供。ネスト内の任意ブロックを個別にドラッグするNotion相当の挙動は未完成。

## データベース

テキスト・数値・セレクト・日付・チェックボックスのプロパティ。基本フィルターは全プロパティの文字列部分一致、ソートは単一フィールドの昇順/降順。ボードは最初のセレクト、カレンダーは最初の日付を使う。カード・日付へのドロップで実データを書き換える。行は独立したページ本文を持たない。Relation/Rollup/Formulaは未実装。

## ファイル

添付は選択されたファイルをコピーする。最大20MB。画像は専用プロトコルから表示し、一般ファイルはクリック後の保存ダイアログで取り出す。Markdown/HTMLを新規ページとして読み込む（10MBまで）。ページをMarkdown/HTML/JSONで書き出す。添付ファイルを同梱するポータブルExportやNotion ZIP Importは未実装。

## 完了判定

機能の実装、実操作、保存、復元を別々に追跡する。実機検証の記録がない項目をOBSERVED/検証済みに昇格させない。P2未実装や参照製品の内部仕様UNKNOWNが残るため、依頼全体は継続開発中。
