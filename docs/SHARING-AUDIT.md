## 現在の共有候補

Gitインデックスのファイルと、ignore対象外の新規ファイルを列挙し、作業ツリーの内容を検査しました。依存フォルダやローカルデータを検査済みの共有物に含めません。

| 検査                   | 結果・対象                                                                                                                                                            |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| APIキー・認証情報      | GitHub/サービスキー/AWS/Google/Slack形式、秘密鍵、認証情報入りURL、資格情報のリテラル代入を検査。該当候補なし                                                         |
| 個人データ             | ユーザー固有の絶対パスと未承認メール表記の該当なし。seed・テスト入力・画像も確認。第三者ライセンスの著作者2メールのみ表記を保持                                       |
| Notionのコード・素材   | Notion ASARや抽出コードは収録なし。公開ヘルプのHTML/AX原本も現在の共有対象から除外。依存・独自素材・テスト画像の由来を [ASSET-PROVENANCE](ASSET-PROVENANCE.md) に記録 |
| バイナリ               | アイコン2・テスト画像1・Folio画面3だけをhashで許可。未確認/変更済みバイナリは検査失敗                                                                                 |
| ローカルデータ・生成物 | DB、添付、バックアップ、キャッシュ、node_modules、ビルド、trace、秘密鍵等はignore。追跡済み原本も明示的にGit対象から除外                                              |
| 保存と復元             | 元の解析12ファイルは全て同じ場所に保持。処理前後のSHA-256が一致。GitのD表示はインデックス上の除外で、ディスク上の削除ではない                                         |

機械検査は [sharing-scan.json](validation/sharing-scan.json)。パターン検査とファイル/画像の確認であり、未知の形式の秘密情報や任意の個人名・住所、全ての著作物との類似性を検出する万能な審査ではありません。アプリの脆弱性診断や適用契約の法務判断も別です。

## 既存履歴に残るもの

初回コミット `abb1e3131d1b4cab6aee4560c6d8aa819859bc29` を含むローカル到達可能な全refsのblobを検査しました。秘密鍵/APIキー形式は検出しませんでしたが、以下が残っています。

- `docs/MCP-CONNECTION.md`、`docs/PROGRESS.md`、環境/検証manifest、自作アプリREA原本内のユーザー固有の絶対パス。
- `research/evidence/rea-capture_browser_scenario.json` に公開NotionヘルプのDOM/AX・ページHTML。非公開ユーザーページのdumpではありませんが、そのまま再配布する対象にはしません。
- Git commitのauthor/committerに1種類のメールIDと作者名。検査レポートには値を出していません。著作者の通常のGit帰属情報ですが匿名化済みではありません。

到達不能なローカルobject、取得していないremote refs、他端末のcloneやGitHubのキャッシュを網羅した検査ではありません。今回の変更を通常pushしても、過去コミットの内容は消えません。履歴を含めて外部共有する場合は、現在のツリーから新規の履歴を作るか既存履歴を処理するかを別途決める必要があります。今回はどちらも実行していません。

## 原本を保持する方法と共有成果物

`research/evidence/` の12原本を `git rm --cached` で追跡から外し、`.gitignore` に追加しました。元ファイルの削除・移動・内容変更はしていません。以前の研究文書は残し、共有用の参照先を追記しています。

選択/匿名化した証拠は [docs/rea](rea/README.md)、元のテスト結果は [docs/validation](validation/README.md)。公開ページの本文を丸ごと配布せず、Evidence ID・原本hash・解析の統計・制約を収録しています。

`npm run review:export` は検査済みの現在のファイルだけを `output/review/folio-review.tar.gz` に保存します。`.git` や除外原本を含めず、展開後の一覧と全ファイルのhashを照合します。`output/review/manifest.json` がそのアーカイブのhashと内容一覧です。これが今回、履歴の問題と分けて渡せるレビュー資料です。外部へのアップロードは行いません。
