# W3公開チェックポイント — 2026-11-04

R6を基点に実装したW1〜W3をまとめたローカルデスクトップ開発版です。機能実装・統合・検証の基点は `89729115a60e6bee9804e2a7cb6ca28fe1caf11c`。GitHubへの反映用ブランチでは同じ製品コード・テストを使い、説明書の更新、ローカル絶対パスの除去、確認済みの合成画面と検証記録の追加だけを行っています。

既存のR6履歴を保持し、W1〜W3を一つの公開用コミットにまとめました。個人のローカルパスを含む開発途中の履歴、セッション原本、実データ、DB、ビルド生成物は追加していません。元の開発用worktree・履歴・起動中アプリは保持しています。

## 使えるようになったこと

| 段階 | 実装範囲 |
|---|---|
| W1 | DB設定メニュー、ボード本文抜粋、タイトル優先・一致文脈付き検索、Markdownのタイトル往復、途中入力とフォーカスの保持 |
| W2 | SQLite・assets・manifestの完全バックアップ検証と新workspace復元、文脈付きバックリンク、標準/ワイドのページ幅 |
| W3 | Calloutと簡易表、文脈に応じた操作UI、ID・clipboard・Markdown/HTML・履歴・復旧との統合 |

Calloutはメモ・ヒント・注意の3種類。解除すると子ブロックを保持して通常の本文へ戻せます。簡易表は最大100行・20列で、行/列の追加・削除、見出し行、Tab/Shift+Tab移動、末尾Tabで行追加、Command+Enterで表の外へ移動できます。横長の表だけがスクロールします。

セル内は段落・改行・装飾・リンクに対応します。結合セル、セル内画像/リスト、入れ子表は対象外です。対応できないHTML表を内容を落として取り込む前に拒否します。新ブロックのMarkdown表現は読みやすいHTMLで、Folio内での往復を検証しています。

## 起動と再現

macOSのGUIセッションで、リポジトリのルートから実行します。

```sh
npm ci
npm run setup
npm run build
node scripts/r9-demo.mjs
```

デモは `output/r9-demo/data` に専用の合成データを作ります。既存データを指定せず、再起動後はデモ内の編集を保持します。[W3操作手順](W3-DEVELOPMENT.ja.md)、[W2バックアップの操作](W2-DEVELOPMENT.ja.md)、[画面](screenshots/README.md)も参照してください。

```sh
npm run check
npm test -- --maxWorkers=4 --testTimeout=15000
npx playwright install chromium
npx playwright test
```

全体E2Eは実Electron操作とブラウザー部品の試験を含みます。専用データを使いますが、GUI・OSクリップボードに触れます。

## 保存形式と戻し方

新ブロックを含む本文だけ `doc.schemaVersion = 2` にします。通常の本文は1を維持し、SQLite、Page、完全バックアップの既存形式は変更していません。各プロセスで最初のrich本文のDB変更前に検証済みバックアップを作成します。バックアップが失敗した場合はDB変更を止め、durable draftを保持します。保存結果不明を無条件で再送する契約には変えていません。

コードを旧版へ戻すだけでデータも戻るとは扱いません。旧版で使う場合はバックアップを新workspaceへ復元し、現行データを保持してください。Markdownの取込は完全workspace復元ではありません。

## 実装体制と性能の範囲

OpenCode Go経由の実 `opencode-go/deepseek-v4.1-flash`（high）を主力に、初期10枠（実装4・調査4・独立QA2）を別worktree・単独所有ファイルで実行しました。親Codexが共有境界・統合・最終検証を担当しました。追加DeepSeekレビュー2回は最終報告が不成立のため不採用で、別のCodex担当による静的点検と区別しています。セッション原本はローカルに保持しています。

同じMac・通常ページ300・DB行200の固定合成データでW2→W3を逐次比較しました。起動は新規プロセス5回、検索/DB読込はwarm-up後20回です。

| 対象 | W2 median / p95（ms） | W3 median / p95（ms） |
|---|---:|---:|
| 起動 | 1106.56 / 1497.78 | 1002.62 / 1214.25 |
| 検索IPC | 11.85 / 15.00 | 12.35 / 15.80 |
| DB読込IPC | 8.00 / 8.60 | 8.75 / 10.90 |

ボード/テーブル切替時の追加レコード読込は両版とも0件、初回表示は200件でした。既存アプリを起動したまま保持し、OSキャッシュと背景負荷は制御していません。物理cold-cache測定・速度保証・優劣判定ではありません。
