# R5 合成デモの操作

起動: `<workspace-root>/Folio-r5-20261028/開く_R5合成デモ.command`。
保存先はvalidation専用 `output/r5-demo/data`。実workspaceとR4デモには触れない。

1. サイドバーの「新しいデータベース」で名前を入力し、作成する。
2. 「新規行」で追加し、名前・メモ・見積・完了を入力する。行の右矢印で本文を編集する。
3. ビュー名を入力し、「新しいビュー」でテーブル・ボード・ギャラリーなどを追加する。
4. 「フィルター・並べ替え・グループ」を開き、条件を設定する。条件に合わない新規行も「追加したページを開く」から開ける。
5. 上部が「保存済み」になってから終了し、同じ起動ファイルで開き直す。

編集中のグループ対象セルは入力欄を離れるまで元の位置に残り、その後に新しいグループへ移動する。数値の「-」など未完成の入力は保存完了にしない。保存結果が不明なら画面の結果確認ボタンで同じ操作を照会する。

初回DB作成時の `workspace.sqlite.pre-r5-records-*.sqlite` はSQLite単体のsnapshot。添付を含む完全backupではない。旧DBのサンプルは変換せず保持している。
