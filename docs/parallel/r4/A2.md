# A2 — Record surface

対象: `codex/r4-record-ui`。H0 `af9132ea405212a76d3b2c88f76c1b57cb98a3b9` を独立実行repoへ複製した担当worktree。元repo/H0/ユーザーデータの変更なし。

## 実装

- 既存 `RecordPage` のtitle/property callbackと本文slotを再利用。`mode="side"|"full"` は同じarticleの属性/CSSだけを変更し、Editor subtreeの再生成を要求しない。mode省略時は従来inline画面。
- 切替・閉じるボタンとEscを追加。`onClose`（なければ`onBack`）へ通知し、元の行・scroll・focusの保持/復帰はApp側の責任。本文Editorのslash、ブロック選択、menu/dialog、IMEがEscapeを扱っている時は閉鎖へ流さない。
- `conflict` / `unknown` / `blocked` を既存保存状態へ追加。unknown時は `onResolve` による「保存結果を確認」だけを提示し、無条件の再送は提示しない。
- `editingBlocked` でtitle/propertyを抑止。本文EditorはCoreが同じlockを適用する。draftや保存queueは画面内へ新設していない。
- `editablePropertyTypes` は任意の型許可一覧。指定時は一覧外propertyを表示したまま編集不可。省略時は既存fixture互換。titleラベルは既存の「レコードのタイトル」を維持。
- `propertyInputTexts` / `onPropertyInputTextChange` でnumberの途中入力をApp所有のまま共用PropertyFieldへ渡す。A3の同名inputText契約が統合依存。数値欄の初期raw値も親が用意し、未完値の離脱/終了を親側で保護する。
- 専用CSSでA5のcontent幅/余白/行高/文字サイズtokenを利用。global CSS/database.css変更なし。

## 接続口

親は同じrecord/sessionに対して同じRecordPage/Editor keyを維持し、position:relativeの有界領域内へ表示する。side/fullはmodeだけ変更する。Appのsession/coordinatorがtitle/doc/valuesと保存状態を所有し、閉鎖時にもdraftを保持する。mode変更時の別session作成・キー変更は禁止。

```tsx
<RecordPage
  pageId={record.pageId} record={record} draft={draft} properties={properties}
  mode={mode} onModeChange={setMode} onClose={closeAndRestoreOrigin}
  onBack={closeAndRestoreOrigin} editingBlocked={editingBlocked}
  editablePropertyTypes={["text", "number", "checkbox"]}
  saveState={status} onResolve={queryOriginalOperation}
  onTitleChange={editTitle} onValueChange={editValue} body={existingEditor}
/>
```
