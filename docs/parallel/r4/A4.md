# R4 A4 — Editor commands

Base: H0 `af9132ea405212a76d3b2c88f76c1b57cb98a3b9` plus A0's Editor `editable` prop/effect setup. Branch `codex/r4-editor`.

## Inventory and change

H0 already has slash filtering, arrow selection, Enter application, Esc cancellation, top-level multi-block selection/move/duplicate/delete and nested sibling operations. These are present in source; this inventory is not a fresh execution result.

The slash implementation previously dispatched query deletion and conversion separately, with no explicit undo boundary. R4 builds them in one Tiptap chain, checks that the source range is still the displayed query, checks that the command can run, and isolates the transform from typing before/after it in history. One Undo is intended to restore the typed slash query and previous block type. Heading commands now set the requested level instead of toggling an already matching level back to a paragraph.

Filtering includes command labels, hints and aliases and accepts whitespace-separated search terms. Arrow selection updates its ref synchronously and scrolls the selected option into view. Esc records the dismissed query so a harmless focus/metadata transaction cannot reopen it until the input or selection changes. Read-only mode closes the menu. Esc for selected blocks now consumes the key before record navigation.

## Parent Escape finding

ProseMirror's `captureKeyDown` consumes even a plain Escape key, so RecordPage cannot rely on a bubble handler's `!defaultPrevented` to close after the slash menu is dismissed. A0 and A2 were informed of this source-backed cause of the failing presentation test. The RecordPage-owned fix is separate from this commit; A2 should handle plain Editor Escape in the capture phase after checking composition and inner overlays.
