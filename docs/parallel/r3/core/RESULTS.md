## Implemented

- Shared read-only record projections, named callbacks and reserved request shapes, Editor documentId supplied by App, and the R3 contract/plan/acceptance documents. The reserved RecordRequest is deliberately **not** registered in requestSchema or live IPC yet.
- Read-only legacy preflight inventories current and history-only row identities per database and reports unsupported/malformed JSON and schemas without rewriting source bytes. This is not itself a migration or a full validation of every future field.
- A transaction-required composite-key mapping allocator avoids collisions with existing Page IDs and allocated record IDs, reuses committed mappings, and can roll back with page changes. Nothing invokes it during startup.
- Experimental record repository primitives support transaction-required membership initialization and a revision-checked atomic title/value patch with prior title/doc/value history. Property ACK returns a projection without doc, so it cannot itself supply a stale document. The primitives are not wired to the application, and do not yet constitute a complete storage migration, history restore, recovery or user-facing record workflow. In particular, ordinary `Store.update` does not snapshot membership values and `restoreVersion` does not restore them; this must be addressed before integration.

## Required work not complete

Live Database 3 conversion, pre-migration SQLite/assets snapshot, unknown-schema blocking at actual migration, version bump/old-binary rejection, transactionally creating/restoring/duplicating/trashing records, legacy-history restore adapter, record-version restore, App's PendingEdits and IPC connection, search/link/sidebar behavior, recovery/backup attachments, full migration failures/retries across restarts, scale measurements, and all integration with other lanes remain unfinished. Existing whole-rows writes remain in the v2 application; the v2 path must be disabled for converted records before enabling the new schema. Existing user data has not been migrated.
