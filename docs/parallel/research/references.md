## REF-01 で確認した記述

- 選択したテキストに `cmd/ctrl + K` でリンクを追加できる。
- `cmd/ctrl + F` はページ内検索、`cmd/ctrl + P` / `cmd/ctrl + K` は検索または最近のページへの移動。
- 太字・斜体・取り消し線などの書式ショートカット、`/turn`、`/color` などが列挙されている。
- 「これらの説明は英語/QWERTY キーボード向けで、国際化は roadmap」と明記されている。
- 取得した本文は途中で切れており、選択・複数選択・リンク取消の節全体は確認できていない。このため REF-01 に書かれていない挙動を「文書化済み」と扱わない。

## REF-02 で確認した記述

- 行の左に `+` と `⋮⋮` のハンドルが現れる。
- `⋮⋮` をクリック&ドラッグしてブロックを移動できる。クリックすると `Turn into`、`Duplicate`、`Move to`、`Delete` などのメニューが開く。
- `/` メニューでブロック追加や操作ができる。
- ドロップ可能な位置、ドラッグ取消、Undo/Redo、複数ブロック移動の境界は記載されていない。

## REF-03 で確認した記述

- ページを無制限にネストでき、トグルで開閉できる。
- ページをドラッグ&ドロップして並べ替えられる。
- ドラッグ中の表示、ドロップ領域、フォーカス・選択の遷移、取消は記載されていない。

## REF-04 で確認した記述

- サブページはページ内のページとして作成できる。
- サイドバーで子ページを親のトグル外へドラッグすると親から出せる。
- サイドバーで別のページへドラッグすると、そのページのサブページにできる。
- ドロップ位置の表示、キャンセル、キーボード操作、フォーカス復帰は記載されていない。

## REF-05 で確認した記述

- ダイアログは `dialog` role と `aria-modal=true` を持ち、外側は不活性になる。
- 開いたときフォーカスは内側へ移り、Tab / Shift+Tab は内側で循環する。
- Escape で閉じ、閉じた後は呼び出し元へフォーカスを戻す（呼び出し元が消えた場合などの例外あり）。
- これは W3C の設計契約であり、Notion のモーダルが同じ挙動をするという実測ではない。

## 使っていない資料・領域

- 非公開の個人ページ、顧客ページ、共有リンク、未公開コード、未公開素材、Notion アプリ内部の抽出物は参照していない。
- Notion ワークスペースへのログイン、既存ページの閲覧・変更、DB の作成は行っていない。
- 公開ページの取得は上記 5 件のみ。HTTP 取得の生ログは `output/agent-workspace/logs/` ではなく本ファイルの記録に留める（外部ページ本文は保存しない）。
