# 優先順位と未確認の差分候補

この文書の優先順位は **比較調査を前に進める順序** であり、製品実装の優先順位を確定するものではない。参照実測が NOT_RUN の現時点で、確定した差分は **0 件**。以下はすべて「確認すべき候補（hypothesis）」で、事実として扱わない。

## 優先度の定義

| 優先度 | 意味 | 現在の該当 |
| --- | --- | --- |
| P0 | 他のすべての比較をブロックする前提（権限・環境記録） | U01 / U02 |
| P1 | 日本語環境の主要リスク、または Folio 側の既知未解決で比較の土台が不安定 | N08 / N09 |
| P2 | 公式文書が細部を説明せず、比較結果が操作体験に直結する | N03 / N04 / N05 / N06 / N07 |
| P3 | Folio 側の自動回帰が安定しており、参照実測の追加でも差分リスクが相対的に低い | N01 / N02 |

## P0: 参照実測の前提

- **U01 権限**: テスト専用 Notion 領域（URL・アカウント・保存可能範囲）の明示許可。許可がない限り、ログインもページ作成も行わない。
- **U02 環境記録**: Notion の版・OS・言語・theme・viewport・zoom・入力方式・surface を実測開始時に記録する。記録なしの観測は比較に使わない。
- **U10 実行環境**: この Harness セッションの workspace-write sandbox では Chromium の子プロセス sandbox を初期化できず、Folio の GUI E2E はアプリ起動前に NOT_RUN。sandbox 制約のない通常のデスクトップセッションで、同じ commit・build・コマンドを再実行する。テストの期待値や sandbox 設定を変えて迂回しない。
- 解除条件を満たすまで N01〜N09 の reference は NOT_RUN、comparison は UNKNOWN のままとする。

## P1: 先に解消・観測するもの

### N08 物理日本語 IME（U03 / U08）

- 理由: 公式ヘルプ自身がショートカット説明を英語/QWERTY 向けと明記し、国際化は roadmap としている。日本語入力の変換・候補選択・取消・再変換は、Folio の日本語 UI にとって比較価値が高いにもかかわらず、自動化できていない。
- 現状: 物理 IME は NOT_RUN。合成 composition のテストは補助証拠に留める。
- 次の一手: 人間の観測者を確保し、同一の入力手順を Folio と許可済み Notion 領域で実施する。OS/IME 版、キー列、画面、保存結果、観測者を記録する。
- 比較への昇格条件: 物理 IME の実測が両側にあり、同一入力方式で観測されていること。文書だけでは昇格しない。

### N09 ページツリー移動（U04）

- 理由: Folio の既存全体 E2E でページツリー移動 F11 が FAIL し、原因が未特定。Folio 側の状態が不安定なまま Notion のドラッグ結果と比較すると、差分の帰属を誤る。
- 現状: Folio は PARTIAL。許可済み Notion 実測は NOT_RUN。
- 次の一手: 失敗時のイベント、dragstart/drop の有無、move IPC と ACK、選択・フォーカス、前後文書を保存して切り分ける。Research はアプリを変更せず、再現証拠と提案を残す。
- 比較への昇格条件: Folio 側の再現条件が整理され、少なくとも同一手順の複数試行で状態が説明できること。1 回の PASS で既知の間欠失敗を解消扱いにしない。

## 作業順序（提案）

1. U01/U02 を満たす（許可と環境記録）。満たせない場合は NOT_RUN を維持する。
2. N08 の物理 IME を人手で実施する（P1）。
3. N09 の Folio 側既知失敗を切り分ける（P1、アプリ変更はしない）。
4. N03/N04/N05/N06/N07 の細部を実測する（P2）。
5. N01/N02 を同一 fixture で再確認する（P3）。
6. 各段階で `parity-matrix.json` の reference と comparison を更新し、根拠のない MATCH を追加しない。

## この担当が行わないこと

- アプリ本体・機能コード・共有型・スキーマ・他担当の文書の変更。
- Notion の非公開ページ、顧客データ、未公開コード・素材の取得。
- 許可のないログイン・ページ作成・既存ページ操作。
- 合成 composition を物理 IME の結果として記録すること。
