# Frozen comparison API v1
Node only, no browser/Electron/native services. runtime/bundle.cjs is a CJS runtime exporting actual Folio schema, validation and PM/Yjs functions. Import default r from '../runtime/bundle.cjs'. BLOCK_TYPES use attrs.id, not blockId. No random ID repair. Input document is actual Folio validDocument JSON, schemaVersion metadata is stripped by PM; normalize output via r.versionDocument(state.doc.toJSON()), preserving an explicitly authored root schemaVersion.
Each adapters/b.mjs and adapters/c.mjs exports createHarness({document,clients=2}). Return {state(index),doc(index),local(index,fn),sync(),undo(index),redo(index),close(),serverDoc(),diagnostics()}. state returns PM EditorState; doc returns normalized JSON; local calls fn(state) -> Transaction then applies; sync is synchronous and delivers all pending candidates until fixed point (bounded). Use identical initial seed, preserve block IDs. undo/redo return boolean. No product blockIdentity random repair plugin. Shared seed validation is separate. C uses collab + history and actual PM server doc/version/step log, receiveTransaction and sendableSteps. Reject malformed server projection without discarding client intent. B uses actual ySyncPlugin/yUndoPlugin EditorView in jsdom Node virtual DOM; bind globals only during harness lifetime, restore on close; no GUI. Proposals/state storage are volatile comparison evidence ONLY, not durable production network.
Scenarios may build PM transactions with r.Step, r.Transform, r.TextSelection. Node blocks have id; text positions start1. A simple doc [{paragraph,id:p1,text:abc},{paragraph,id:p2,text:xyz}]. Move with tr.delete(from,to).insert(target,node) is intentionally adversarial. Legitimate baseline text edits must converge and preserve both. all-safe-refuse is a failed normal-operation case.
No shell permission in workers. Write only assigned output and REPORT.md; parent runs tests. Do not implement dynamic discovery or speculative alternate APIs. Report unsupported cases explicitly.
