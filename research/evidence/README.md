# ローカル解析原本

REAの応答原本・公開ページのDOM/AX・環境記録はこのフォルダにローカル保存します。
原本は削除していませんが、2026-10-26のレビュー準備でGitの追跡対象から外しました。
新しいcloneにはこの説明だけが含まれます。

外部レビュー用は [docs/rea/README.md](../../docs/rea/README.md)。原本のSHA-256、Evidence ID、解析対象、coverage、制約を残した派生資料です。
公開サイトのHTML・スクリプト断片、端末固有のパス、ファイルシステム識別情報は共有用の資料に含めません。

`node tools/rea/client.mjs` は原本をこの場所へ出力します。再解析では同名ファイルが更新されるため、既存の証拠を残す場合は先にプロジェクト内の無視対象へコピーしてください。
既存Git履歴の扱いは [共有前検査](../../docs/SHARING-AUDIT.md) を参照してください。
