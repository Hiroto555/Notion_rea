# 比較からの仕様化と改善

| 根拠                                 | Folioへの反映                                             | 検証/差分                                                         |
| ------------------------------------ | --------------------------------------------------------- | ----------------------------------------------------------------- |
| 公開ヘルプのページツリーと折りたたみ | parentId/positionのツリー、展開状態保存                   | 150階層・循環拒否。無制限の性能は主張しない                       |
| 公開編集ヘルプのハンドルと/メニュー  | トップレベルハンドル、スラッシュ検索、範囲選択、複製/移動 | 実ドラッグ・複製Undo/Redo。任意のネストDnDは未完                  |
| キーボードヘルプの⌘K/⌘N              | 全文検索とページ作成                                      | 検索直後Enterの古い結果問題を実機で発見・修正                     |
| Notion形式の `>` と `                | `                                                         | トグルと引用の入力ルール                                          | `>`トグルを実機検証。一般Markdownの引用インポートは別のパーサー経路 |
| 自作アプリの画像確認                 | TaskItemのnode-view属性を明示                             | チェックと文章が上下に分離する崩れを修正し再撮影                  |
| NotionネイティブAX                   | ローカル操作と表示領域の分離を確認                        | タブUI/アカウント構成の複製は今回未実装                           |
| 独立した要件：オフライン保存         | SQLite/assetコピー/backup                                 | 保存・再起動・integrity_check。Notion内部方式と同じという主張なし |

ピクセル単位の差分画像、同一文書をNotion/Folioの両方で編集する比較、IME入力の実比較は未完了。独自CSSカバー・独自名称を使用し、Notion素材はコピーしない。
